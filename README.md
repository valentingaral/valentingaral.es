# valentingaral.es

Personal website of Valentin Garcia Alcocer (Valentin Garal).

- `index.html`: home page
- `design.html`: design archive (2008 to 2015)
- `assets/`: images and logos
- `CNAME`: custom domain for GitHub Pages

To edit a text: open the HTML file on github.com, click the pencil icon, change the text and commit. The site updates in about a minute.
